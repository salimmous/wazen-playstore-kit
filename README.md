# Wazen — Play Store Assets & Release Portal

**Live Client Link:** https://salimmous.github.io/wazen-playstore-kit/

This standalone portal gives the client direct browser access to:
- **126 verified Light-Mode RGB PNG screenshots** (`< 2 MB` each, zero alpha) across **5 store locales** (`ar`, `en-US`, `fr-FR`, `de-DE`, `es-ES`):
  - Store Icon (`512×512`)
  - Feature Graphic (`1024×500`)
  - Phone (`1080×2160`)
  - 7-inch Tablet (`1080×1920`)
  - 10-inch Tablet (`1440×2560`)
- **5 per-locale ZIP bundles** in [`zips/`](zips/) (`~14.5 MB` each) ready for Google Play Console upload.
- **Copy-ready Store Release Notes & Metadata** (`What's New` for iOS `2.0.2 Build 64` & Google Play `v7.9 Build 70`).
- **Release Docs & Git Log** in [`docs/`](docs/).

> **Security Note:** Signed app binaries (`.ipa`, `.aab`, `.apk`) and private source code are intentionally excluded from this public repository.
